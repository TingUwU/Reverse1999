# ⏳ Reverse: 1999 Battle Simulator (SwiftUI)

以手遊《重返未來：1999》為靈感，使用純 **SwiftUI** 與 **AVFoundation** 打造的橫向回合制神秘學家卡牌戰鬥與編隊模擬器。

---

## 📖 專案特色 (Features)

* **四階段完整遊戲流程**：
  * **封面啟動畫面 (`.home`)**：點擊全螢幕任意位置進入時代迴廊。
  * **戰前編隊系統 (`.preparation`)**：支援 4 位神秘學家陣容位置點擊即時輪替、關卡目標與敵方情報預覽。
  * **動態回合制戰鬥 (`.battle`)**：
    * 支援手牌抽取、行動槽（最多 4 動）指派與撤回。
    * 施放普通神秘術（現實／精神創傷、Buff、Debuff、治療）。
    * **至終的儀式（大招）專屬全螢幕 Cut-In 動態特寫**。
    * 我方前衝攻擊、敵方受擊震動（Shake Animation）、跳字傷害與治療數值回饋。
  * **戰鬥勝利結算 (`.victory`)**：呈現結算回合數、評級獎勵徽章與 MVP 角色立繪展示。
* **無縫音效體驗**：整合 `AVAudioPlayer` 單例架構，在切換不同遊戲場景時保持全域背景音樂（BGM）流暢循環不中斷。
* **跨平台與響應式適配**：針對 iPad / iPhone 橫向畫面進行等比例版面配置（Compact / Regular 適配）。

---

## 🛠 技術棧 (Tech Stack)

* **UI 框架**：SwiftUI (iOS 17+)
* **音訊處理**：AVFoundation (`AVAudioPlayer`, `AVAudioSession`)
* **動畫與過渡**：SwiftUI Spring Animations, Custom Transitions (`.scale`, `.opacity`, `.offset`)
* **架構模式**：Declarative UI + State-driven State Machine (`GamePhase`)

## 🎮 操作指引 (How to Play)

1. **進入戰局**：在首頁封面點擊任意處進入「戰前編隊」。
2. **調整陣容**：點擊隊伍卡片可循環換位，確認後點擊右下角「開始行動 (-20)」扣除活性進入戰鬥。
3. **選擇卡牌**：點選下方手牌填入右上方的行動槽（最多可選擇 4 張，點擊行動槽卡牌可取消）。
4. **發動攻擊**：選滿 4 張或手動點擊「出擊」，角色將依序發動神秘術與至終的儀式。
5. **勝利結算**：擊敗所有敵方單位後自動進入勝利結算畫面，點擊「返回戰前編隊」可重置狀態再次挑戰。
